hexo github 博客搭建
使用hexo github搭建一个自己的博客
Oct 10, 2025

第一步，前期准备工作

1.Github账号
-需要拥有一个Github的账号，没有的话可以 官网 去注册一个。
-参考教程https://blog.csdn.net/yaorongke/article/details/119086305

2.Git(用于部署到github):

  • 从 官网 下载，默认配置安装即可
  • 验证：输入 git --version，显示版本号即成功
    -教程参考https://blog.csdn.net/yaorongke/article/details/119085413

3.Github账号

-需要拥有一个Github的账号，没有的话可以 官网 去注册一个。
-参考教程https://blog.csdn.net/yaorongke/article/details/119086305

4.Node.js(运行hexo的环境)

  • 从 官网 下载对应系统的安装包（推荐 LTS 版本）
  • 安装时勾选“Add to PATH”，确保环境变量生效
  • 验证：打开 PowerShell 输入 node -v，显示版本号即成功
    -修改环境变量时，遇见了一些问题：打开电脑的 编辑系统环境变量 ，点击环境变量，选中path一栏，进行比编辑，

第二步，在github中创建自己的仓库

  • 进入github网站中点击右上角的头像，再点击Your repositonries
  • 点击new按钮，创建自己的仓库
  • 填写自己的仓库名，格式为<用户名>.github.io,然后点击Create repository
  • 点击creating a new file创建一个新文件，作为我们网站的主页
  • 新文件的名字必须为index.html，内容随意，填写之后点击Commit new file提交
  • 找到code并进入，找到index.html文件进行编辑，写入形成网页的代码，保存修改
  • 点击settings,在左边列表找到page，点击后就能看见自己建立的网页地址，点击就能进入
  • 这时的网站是十分简陋的

第三步，安装hexo

  • 采用hexol来构建我们的博客网站，用hexo进行编辑，不用开发，只要一些必须的配置（如：Node.js），hexo官网：https://hexo.io/zh-cn/
  • 在终端中用 npm install -g hexo-cli ，安装hexo
  • 查看版本 hexo v
  • 建立一个项目,并初始化 hexo init hexo-blog
  • cd hexo-blog
  • npm install
  • 本地启动 hexo g
  • 在执行 hexo s
  • 启动服务器，进入 http://localhost:4000

第四步，创建文章

  • 建立一个测试文章 post_asset_folder: true
  • hexo new post 测试文章
  • 执行完成后，会在hexo-blog\source_posts 上形成一个文件：测试文章（用于存放图片），其中测试文章.md是编辑博客用的
  • 图片上传看官方：https://hexo.io/zh-cn/docs/asset-folders.html (主题可改可不改)
  • 本地启动 hexo g -d
  • hexo s

第五步，个性化展示

  • 浏览器tab页名称，修改根目录下的_config.yml中的title字段。（用记事本打开）
  • 博客标题，主题目录 themes\fluid 下 _config.yml 中的 blog_title 字段
  • 主页正中间的文字，主题目录 themes\fluid 下 _config.yml 中的 text 字段
  • 修改好后保存

第六步，部署到github的page上

  • 先安装hexo-deploy-git
  • 在终端上执行 npm install hexo-deployer-git –save
  • 修改根目录下的_config.yml文件，配置 GitHub 相关信息
  • deploy:
    type: git
    repo: git@github.com:你的用户名/你的仓库名.github.io.git （用户名为github的）
    branch: main
  • 编辑好以上信息，在终端执行 hexo g -d ,即可部署成功
  • 打开github上的个人博客即可看到效果
